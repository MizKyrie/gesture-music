手势合成器使用说明

这是一个用电脑摄像头、把手势实时变成音乐和弦的网页乐器。基于 MediaPipe 手部追踪 + Web Audio 合成。

怎么开始

点击屏幕中央「▶ 开始」 → 允许摄像头 → 允许音频，即可演奏。

左手 · 数手指选根音 + 上下移升降

  • 1️⃣ 1 根手指（食指） → 级数 I
  • 2️⃣ 2 根手指（食+中） → 级数 II
  • 3️⃣ 食+中+拇指 → 级数 III
  • 4️⃣ 4 根手指（不含拇指） → 级数 IV
  • 5️⃣ 5 根手指全伸 → 级数 V
  • 🤘 金属礼（食+小指） → 级数 VI
  • 🤟 我爱你（拇+食+小指） → 级数 VII
  • ✊ 握拳 → 停止发声
  • 手上移（越过 # 区） → 升半音 #
  • 手下移（越过 b 区） → 降半音 b
  • 手中间 → 还原 ♮

右手 · 伸食指指圆盘（角度=家族，半径=形态）

  • 把右手只伸食指，指向画面右侧的彩色圆盘
  • 角度选家族：上=Maj、右上=Maj7、右下=7、下=Min、左下=m7、左上=ø7（顺时针排列，Maj7 挨 Maj、m7 挨 Min）
  • 半径选形态：近圆心=①第1形态、中圈=②第2形态、外圈=③第3形态
  • 每家族 3 形态：Maj（Maj / sus4 / drop2）· Maj7（Maj7 / Maj9·drop2 / Maj9·drop3）· 7（7 / 7sus4 / 13）· Min（Min / drop2 / drop3）· m7（m7 / m9·drop2 / m9·drop3）· ø7（ø7 / drop2 / drop3）
  • drop2 = 第二高音降八度；drop3 = 第三高音降八度（开放排列 voicing）；13 和弦用 1-3-b7-13 四音配置

🎛 音色编辑 & 和弦编辑（左上角齿轮展开后）

  • 左上角「⚙」齿轮默认折叠控制面板（为左侧升降区让位），点开后可调调性/音色/音量/颤音，以及音色编辑、和弦编辑
  • 音色编辑：基于任意基础波形，用旋钮调效果器参数（低通截止/共振、起音/释音、延迟、混响），点「▶ 随机试听」播放常用和弦（再点停止），拖动旋钮实时听效果；也可以直接点击底部钢琴键试单音；可新建/保存/删除自定义音色
  • 和弦编辑：每个家族可增删形态（圆盘环数按所有家族的最大形态数统一绘制，形态不足的家族空环带显示浅色「—」），编辑每个形态的名称 / 音程（如 0 4 7 11）/ voicing（原位、drop2、drop3、drop2&4），输入时实时预览音符（以 C 为根音）
  • 右上角有波形可视化，实时显示当前音色播放时的振荡器波形
  • 自定义内容保存在浏览器 localStorage，刷新不丢失；「恢复默认」可回到出厂配置

🎵 音色与颤音（左上角）

  • 音色 7 种：暖色合成 / 纯净 Sine / 明亮 Bright / 复古 Retro / 铃音 Bell（泛音衰减的钟声感）/ 风琴 Organ（谐波堆叠）/ 铺底 Pad（双振荡器 detune 合唱）
  • 「颤音 Tremolo」= 音量颤音 + 立体声：音量按设定速率（0.5~12 Hz）周期性起伏，左右声道反相交替（L 响时 R 弱、R 响时 L 弱），像 Fender 音箱的 tremolo；深度（0~100%）控制起伏幅度，滑杆即时生效

🎵 就近衔接（左上角开关）

  • 打开「就近衔接」后，切换和弦时每个声部会就近移动：共同音保持不动、其他音只走最短距离，过渡顺滑不跳
  • 声部音域自动锁定在 C3~E6 之间并轻度回归中音区，不会越弹越偏；重新起手（握拳）后回到标准 voicing
  • 关闭时使用固定的 drop voicing 排列（drop2/drop3）

提示：画面顶部是级数按钮栏（当前选中高亮）；左侧是 #/♮/b 三个升降区域块（手越过即切换）；右侧是家族圆盘（同心三环代表①第1形态/②第2形态/③第3形态）；中央显示当前和弦名。
