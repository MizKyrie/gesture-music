# gesture-music · 手势合成器

用电脑摄像头，把**手势实时变成音乐和弦**的网页乐器。基于 **MediaPipe Hand Landmarker**（手部 21 关键点追踪）+ **Web Audio API**（实时合成）。

> 🎹 本项目基于开源项目 [ericwei97-cloud/gesture-synth](https://github.com/ericwei97-cloud/gesture-synth) 二次开发。
> 在原版基础上重写了 voicing / voice leading、和弦编辑器、音色编辑器、波形可视化与毛玻璃 UI。

## ✨ 当前特性

- **手势演奏**：左手数手指选级数 I~VII，上下移选 #/♮/b；右手指向圆盘选和弦家族与形态。
- **理论化 voicing**：原位 close、drop2 / drop3 / drop2&4 / drop2&3、转位、开放 spread、rootless A/B、add9、13、11 等爵士/流行常用排列。
- **就近衔接 voice leading**：切换和弦时各声部走最短距离，共同音保持；音域锁定 C3~E6，轻度回归中音区，不会越弹越偏。
- **和弦编辑器**：和弦内音记法（`R b3 3 4 b5 5 #5 6 b7 7 b9 9 #9 11 #11 b13 13`），底部 C4~A5 键盘实时选音/试听，voicing 候选一键切换，支持自定义排列。
- **音色编辑器**：10 个旋钮（低/中/高 EQ、低通、共振、起音、释音、延迟、反馈、混响），支持试听、新建/保存/删除自定义音色，localStorage 持久化。
- **主控三段 EQ**：设置面板内置 Roland 风格 Low / Mid / High 滑杆。
- **波形可视化**：自动电平归一化，按基频截取约 2 个周期，从上升过零点稳定显示。
- **苹果风毛玻璃 UI**：设置面板、和弦盘、顶栏均使用玻璃拟态；中英文分别使用 Noto Sans SC 与 Bungee 字体。

## 运行方式

摄像头需要在「安全上下文」下才能使用，所以**必须用 `localhost` 或 `https` 访问**，不能直接双击打开 `index.html`（`file://` 拿不到摄像头）。

在项目目录下启动任意本地服务器：

```bash
# 方式一：Python
python3 -m http.server 8000

# 方式二：Node
npx serve -l 8000
```

浏览器打开：**http://localhost:8000**

1. 点击屏幕中央「▶ 开始」
2. 允许「摄像头」权限
3. 允许「声音」播放
4. 开始用手演奏 🎶

## 和弦编辑器

- 每个家族可增删形态，圆盘环数 = 所有家族最大形态数。
- 先命名，再通过 **和弦内音 chips** 或 **底部键盘** 选音，实时试听。
- 从 **voicing 候选** 中直接选排列：close / drop 类 / 转位 / spread / rootless A/B 等。
- 可选 `✎ 自定义排列`，手动输入如 `0 7 4 10`。

## 音色编辑器

- 音色库：选择要编辑的预设或用户音色。
- 基础波形：三角 / 正弦 / 锯齿 / 方波 / 钟声 / 风琴 / 铺底。
- 旋钮调节：低音 / 中音 / 高音 / 低通 / 共振 / 起音 / 释音 / 延迟 / 反馈 / 混响。
- 双击旋钮恢复默认值。

## 技术栈

- MediaPipe Hand Landmarker / Face Detector（CDN）
- Web Audio API：合成、滤波、EQ、延迟、混响、立体声颤音
- 原生 ES Modules + Canvas 2D + CSS Glassmorphism
- localStorage 持久化
